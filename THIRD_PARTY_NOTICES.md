# Third-party components and attribution

This source repository does not include third-party repository code or model weights. Clone and install them separately, and review the licenses of each project before redistribution.

- WebToEpub: https://github.com/dteviot/WebToEpub
- epub2txt: https://github.com/ffreemt/epub2txt
- Vietnamese Long Audio TTS: https://github.com/Tanphong254/Vietnamese-Long-Audio-TTS
- HachimiMT-60 Chinese to Vietnamese: https://huggingface.co/ngocdang83/HachimiMT-60-zh-vi. Its model card declares CC BY 4.0; provide attribution and comply with its terms.

The desktop audio worker uses the installed edge-tts Python package and requires an internet connection for synthesis.

No book text, translated manuscript, MP3, model weights, local cache, virtual environment or third-party repository is part of this source repo.
